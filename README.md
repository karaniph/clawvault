## What is ClawVault?

ClawVault is a safety-verified, searchable directory of 49+ skills and integrations for three agent frameworks:

| Agent | Focus |
|-------|-------|
| **OpenClaw** | General-purpose AI agent skills — search, memory, GitHub, payments, WhatsApp |
| **Hermes** | Email, web search, browser automation, memory, GitHub workflows |
| **PicoClaw** | VPS monitoring, backups, uptime, Docker, firewall, and server management |

Every skill is tagged with a safety status (`✓ Safe` / `⚠ Review`) and organized into categories:
**Must-Have · Communication · Security · Dev Tools · Productivity · VPS & Hosting**

## Featured Skills

### OpenClaw
- 🔌 **Composio** — 860+ integrations (GitHub, Slack, Gmail) without auth pipelines
- 🌐 **Web Browsing** — Full browser control for your agent
- 🔍 **Tavily Search** — AI-optimized search with citations
- 🧠 **Memory (LanceDB)** — Long-term vector memory across sessions
- 💬 **Wacli (WhatsApp CLI)** — Send messages and search conversation history
- 📊 **GOG — Google Workspace** — Gmail, Calendar, Drive, Docs & Sheets in one skill
- 🔒 **Clawaudit** — Automated security audit for OpenClaw gateway hosts

### Hermes
- 📧 **Email Skill** — Send and read emails via Gmail or SMTP
- 🖥️ **Browser Automation** — Scrape, fill forms and navigate the web
- 🗓️ **Calendar Manager** — Read and create Google Calendar events
- 🐙 **GitHub Assistant** — Issues, PRs, and repo management
- 📝 **Notion Workspace** — Create pages and update databases

### PicoClaw
- 📈 **Resource Monitor** — Track CPU, memory, and load on a lightweight VPS
- 🛡️ **Firewall Manager** — Inspect and update UFW/iptables rules
- 🐳 **Docker Manager** — Start, stop and inspect containers
- 🔐 **SSL Certificate Manager** — Auto-renew and monitor certificates
- 💾 **Backup Manager** — Automated backups with compression and remote upload
